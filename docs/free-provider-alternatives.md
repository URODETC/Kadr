# Альтернативы Alloha

Проверка 13 сентября 2026. Условия: только бесплатные источники, без хранения видео на сервере, русский и оригинал, субтитры, минимум 1080p.

## Результат

Полностью подтверждённого бесплатного API под все условия пока нет. Не следует подключать источник только по наличию документации или обещанию HD.

| Кандидат | Доступ | Что установлено | Ограничение |
| --- | --- | --- | --- |
| Kinobox | В документации поиск без обязательного токена | Поиск по KP/IMDb/TMDB, iframe и список озвучек; лимит 2 запроса/с на IP | Документация в индексе старая; основной endpoint перенаправляет на файл speedtest, непригоден |
| Vibix | Представитель объявил trial до 3 месяцев для сайтов без трафика | Есть API и готовый плеер; кабинет упоминает полный функционал trial без рекламы | Требуется обращение в поддержку; бессрочность бесплатного доступа и условия после trial не подтверждены |
| Lumex | На странице подключения от 1000 уникальных посетителей/сутки | Заявлены API, 1080p, разные озвучки | Не подходит по порогу аудитории |
| VideoCDN | В старых сообщениях официального канала принимались сайты с любой посещаемостью | Были iframe, API и отдельный VideoAPI для оригинальных языков | Актуальность условий не подтверждена, сайт при проверке недоступен через web-fetch |
| Kodik | Доступ в этой проверке не установлен | Найдены сторонние библиотеки, но недостаточно актуальных первичных данных | Не рекомендован как проверенная замена; чужие токены не использовались |

## Kinobox

[API](https://kinobox.tv/api), [компонент и React-пример](https://kinobox.tv/docs/).
Документированный запрос: `https://kinobox.tv/api/players?kinopoisk=4541515`.
Ответ по документации включает источник, URL iframe, озвучки и строку качества. Это агрегатор внешних плееров, а не гарантия качества медиадорожек. Готовый компонент по документации соответствует требованию использовать готовые решения, но актуальный endpoint при проверке непригоден.

Сетевая проверка: основной адрес перенаправил на `https://speedtest.selectel.ru/1GB`, то есть тестовый файл вместо JSON API. Запрос остановлен по тайм-ауту, временный файл удалён. Этот endpoint исключён из рабочих вариантов. Запрос альтернативного хоста `api.kinobox.tv` завершился ошибкой HTTP/2. Ошибка конкретной сети не доказывает глобальную недоступность.

## Vibix

[Лендинг](https://www.vibix.tv/) ещё указывает 1000 посетителей/сутки и 80% запусков из РФ. Однако [сообщение представителя от 3 февраля 2026](https://zerocoolpro.biz/forum/threads/vibix-nadezhdyi-video-balanser-s-vysokim-cpm.23922/page-8) объявляет trial до трёх месяцев без трафика; 11 февраля представитель подтвердил регистрацию через поддержку. [Кабинет](https://vibix.org/) также содержит описание пробного периода без рекламы с полным функционалом. Это делает Vibix кандидатом для тестового запуска, но не доказанным бессрочно бесплатным источником.

Не отправлено никаких сообщений и заявок. Для обращения готова формулировка: «Запускаем новый сайт без трафика. Нужен бесплатный доступ к API/iframe, фильмы и сериалы 1080p+, несколько русских озвучек, оригинальная дорожка и субтитры. Доступен ли trial и можно ли оставаться без оплаты после него при низкой посещаемости? Какие ограничения API и встраивания?»
