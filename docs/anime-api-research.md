# Переход к аниме: проверка API

13 сентября 2026. Новое направление проекта — аниме. Требования: бесплатные источники, русские озвучки, оригинальный язык и субтитры, лучшее доступное качество для релиза вместо обязательного 4K. Видео должно идти прямо в браузер.

## Подтверждённый кандидат: AniLiberty API v1

- [Официальная документация](https://api.anilibria.app/api/docs/v1/).
- [Официальный репозиторий предупреждает об отключении прежних API](https://github.com/anilibria/docs). Старый AniLibria API v3 для нового проекта не использовать.
- [Объявления разработчиков об адресах нового API](https://t.me/s/AniLibria_Devs).

Живые запросы без токена, cookies и регистрации:

1. `GET https://anilibria.top/api/v1/anime/releases/latest?limit=1` → HTTP 200, JSON.
2. `GET https://anilibria.top/api/v1/anime/releases/10292` → HTTP 200, релиз «История о перекуре за супермаркетом», 10 эпизодов на момент проверки.
3. Первый эпизод содержит непустые `hls_480`, `hls_720`, `hls_1080`. Запросы плейлистов 480 и 1080 → HTTP 200 и содержимое `#EXTM3U`.
4. Плейлист 1080 при запросе с Origin опубликованного сайта вернул `Access-Control-Allow-Origin` с этим доменом. Это подтверждает CORS плейлиста; запуск видеосегментов и декодирование в браузере ещё не проверялись.

Адрес `api.anilibria.app` в этой среде возвращал 403, в то время как официальный альтернативный адрес `anilibria.top` работал. Это не основание обещать одинаковую доступность из всех сетей.

Бесплатность здесь означает фактически проверенное получение публичных данных без платежа или ключа. Условия долгосрочной эксплуатации, лимиты и доступность всего каталога отдельно не подтверждены.

## Ограничения по языкам

В проверенном эпизоде нет списка вариантов озвучки, субтитров или выбора аудиодорожек. В полученном плейлисте нет `EXT-X-MEDIA` с отдельными дорожками. Это не доказывает отсутствие субтитров во всём сервисе, но не позволяет заявить соответствие требованиям японского оригинала, субтитров и нескольких русских озвучек. Содержимое аудио не прослушивалось.

AniLiberty можно рассматривать как источник релизов своей команды и рабочую основу проверки стриминга. Нельзя выдавать его за агрегатор всех студий.

## Кандидат для разных переводов: Kodik

[Исходник готового плагина Kodik для Seanime](https://github.com/Uximy/kodik-dub) описывает выбор озвучки/субтитров и максимального доступного качества. [Клиентская библиотека](https://github.com/negezor/kodik-api-rust) использует ключ API. Это первичные источники авторов интеграций, а не официальные гарантии провайдера.

Официальный публичный способ получения бесплатного собственного ключа без порога аудитории в этой проверке не установлен. Чужие ключи не использовались. Наличие работающего стороннего приложения не подтверждает разрешение на использование его ключа нашим сайтом. Kodik остаётся кандидатом, а не подключённым источником.

## Решение

Техническая основа для аниме найдена: AniLiberty v1, прямые HLS, существующий Shaka-плеер. Выбирать максимальный реально доступный вариант, обычно 1080/720, без апскейла и фиктивной отметки качества. Для завершения исходных требований нужен подтверждённый дополнительный источник японской дорожки, субтитров и других русских студий.

Исследование не меняет опубликованный интерфейс. Видеофайлы и сегменты на сервер не скачивались; проверялись только JSON и небольшие текстовые плейлисты.
