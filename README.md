# Кадр

Минимальный русскоязычный кинотеатр на React, shadcn/ui (Radix), Lucide и готовом Shaka Player. Видео, манифесты и субтитры идут **напрямую от внешнего источника в браузер**. Сервер приложения не скачивает, не хранит и не проксирует видео. Аккаунт и платные ключи не нужны.

## Запуск

Требуется Node.js 22.13+.

```sh
npm ci
npm run dev
```

Адрес печатается в терминале. Проверки:

```sh
npm run typecheck
npm test
npm run build
```

## Реализовано

- Русский интерфейс, адаптивный каталог, фильтры, поиск по стартовой подборке.
- Закладки, история и восстановление позиции в localStorage, отдельно для каждой серии.
- Получение сезонов/серий у источника, последовательный переход к следующей серии.
- Открытие других фильмов и сериалов по числовому ID Кинопоиска через настройки.
- HLS/DASH, выбор качества, озвучки и субтитров, скорость, fullscreen и PiP средствами Shaka.
- Минимум 1920 пикселей по ширине: кинематографическое 1920×818 считается Full HD, 3840×1636 — 4K. Варианты ниже минимума запрещены как для автоматического, так и ручного выбора.
- Перед обычным просмотром проверяются русский звук, оригинал и субтитры; для сериала — несколько озвучек. Затем плеер проверяет реальные дорожки и разрешения манифеста.
- JSON5 + Zod разбирают только нужные поля конфигурации. Код провайдера не исполняется, iframe, реклама и P2P-клиент провайдера не встраиваются.

## Источник и ограничения

Используется публичный endpoint Collaps `https://api.delivembd.ws/embed/kp/{id}`. Схема подтверждена [исходным кодом Lampa](https://github.com/yumata/lampa-source/blob/master/plugins/online/collaps.js) и проверена реальными запросами. Это публичная конфигурация плеера, **не официальный стабильный API с SLA**. К ней браузер обращается с CORS; отсутствие серверного посредника сохраняет клиентский IP для получения и воспроизведения подписанных ссылок. Ссылки не сохраняются в localStorage.

**Все исходные требования по бесплатному контенту пока не закрыты.** При проверке 12–13 сентября 2026 источник вернул русские озвучки, оригинал и субтитры для нескольких популярных фильмов, но их HLS-манифесты содержали максимум 720p. Сайт не подменяет это обещанием 1080p и отказывается запускать такой поток. В других сетях, регионах и для других фильмов результат может отличаться. 4K у обычных фильмов не подтверждено. Изменение формата/CORS/домена провайдера требует обновления адаптера.

В комплекте есть открытый **демофильм «Синтел»**, предоставленный Shaka Project/Blender. Его поток содержит 1080p, 1440p и 4K, оригинальный звук и субтитры (в том числе русские). **Русской озвучки в демофильме нет** — это явно показанное исключение только для проверки плеера, а не замена основного каталога.

Каталог содержит стартовую подборку из 5 позиций, включая демофильм. Поиск по всему Кинопоиску не реализован; произвольные названия открываются по ID. Постеры загружаются с внешних сайтов, атрибуция доступна на `/credits`.

## Что проверено

- TypeScript и 10 тестов адаптера: разбор литералов, запрет выполнения JS, неверные ID/URL, заблокированный контент, порядок сезонов, отсутствие оригинала/субтитров, проверка нескольких озвучек и отсутствие подмены серии.
- Браузер: реальная загрузка списка сезонов «Тьмы», воспроизведение «Синтел», выбор 4K, наличие русских субтитров, восстановление времени просмотра.
- Без live-проверки конкретного фильма нельзя утверждать доступность его 1080p/4K или всех озвучек.

## Структура

- `app/page.tsx` — каталог, модальные окна, история и выбор серии.
- `components/cinema/player.tsx` — готовый Shaka UI, строгий минимум разрешения и загрузка субтитров.
- `lib/cinema/provider.ts` — браузерный адаптер бесплатного источника.
- `lib/cinema/catalog.ts` — стартовая подборка; качество обычных фильмов не заявляется до проверки.
- `scripts/test-cinema.mjs` — автономные тесты без внешней сети.

Приложение не использует медиахранилище, торренты, транскодирование, загрузчики или платные API. Для полноценного использования требуется бесплатный источник, реально предоставляющий необходимые дорожки и качество для выбранных фильмов.
